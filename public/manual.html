업셀 스크립트
컴플레인 대응
강매 금지. 측정·검안 데이터에 근거한 제안만. "권유"가 아니라 "손님 데이터를 보면 이게 맞아요"로 말하기.
렌즈 업그레이드 업셀
상황
고도수(-4.00 이상)인데 저굴절률 선택 시
멘트
"도수가 있으셔서 1.60으로 하면 렌즈가 두꺼워 테 밖으로 나와요. 1.67로 가면 두께가 30% 얇아져서 훨씬 가볍고 보기 좋아요."
근거
검안 도수에 맞는 굴절률 자동 권장(rx 연동). 보기·무게 차이는 실측값으로 표시.
청광·변색 코팅 업셀
상황
용도가 업무·VDT(모니터)거나 야외 활동이 많을 때
멘트
"하루 종일 모니터 보신다고 하셨죠. 청광 차단 넣으면 눈 피로가 덜해요. 야외도 잦으면 변색렌즈 하나로 선글라스까지 돼요."
근거
접객 카드의 '용도' 칸에 맞춰 코팅 선택. 생활 방식에 맞춘 제안.
세컨드 안경 / 선글라스 업셀
상황
단골·재방문, 측정 데이터가 이미 있을 때
멘트
"사이즈가 이미 저장돼 있어서 두 번째 안경은 측정 없이 바로 돼요. 운전용 변색이나 도수 선글라스 하나 더 어떠세요?"
근거
통합 프로필에 9사이즈·도수 저장, 추가 구매 간편. 재방문 계기.
콘택트 병행 업셀
상황
운동·외출할 때 안경이 불편하다고 할 때
멘트
"운동할 때 안경이 불편하시면, 1day 콘택트를 같이 쓰시는 분들 많아요. 도수는 이미 알고 있으니 맞는 제품 안내드릴게요."
근거
검안 도수를 콘택트 도수로 환산. 카탈로그 가격 그대로 표시.
손님 잘못으로 몰지 않기. 매장에서 즉시 1차 대응, 미해결 시 본사로 이관. 모든 건 기록.
손님 접수·매장 1차 대응·본사 연계·보상·처리·로그 기록
도수가 안 맞음 1차 매장
대응
즉시 무료 재검안. 적응 기간(1~2주) 안내. 처방 오류 확인 시 렌즈 무상 재제작.
멘트
"불편하셨겠어요. 바로 다시 검사해드릴게요. 검사 결과 도수가 다르면 렌즈는 무상으로 다시 만들어 드려요."
기준
검안 오류면 본사 비용으로 무상 재제작. 적응 문제면 재검 후 안내.
피팅 불편 (흘러내림·압박) 1차 매장
대응
즉시 재피팅(무료, 횟수 제한 없음). A4 피팅지로 재측정, 벌림각·코받침 재조정.
멘트
"피팅은 언제든 무료로 다시 맞춰드려요. 지금 바로 조정할게요."
기준
피팅은 항상 무상. 측정 데이터 재사용.
파손 (힌지·렌즈) 본사 연계
대응
무상 A/S 기간 내 무상 교체. 기간 경과 시 본사 표준가로 부품 교체. 손님 과실도 부품값만.
기준
A/S 기간: 프레임 1년. 부품은 본사 공급가 그대로 안내.
환불 요구 본사 연계
대응
제작 전이면 전액 환불. 제작 후 단순 변심이면 맞춤 제작 정책 안내. 하자 시 전액 환불·재제작 중 손님 선택.
기준
맞춤 제작품 환불 정책은 주문서 동의로 사전 고지. 하자는 무조건 구제.
제작 지연 1차 매장
대응
지연 사유·새 일정 즉시 알림톡 발송. 약속일 초과 시 소정의 보상(쿠폰).
기준
알림톡 자동 발송(준비완료 알림과 연동).
단계별 처리 기준 본사
등급처리권한
L1 매장재검·재피팅·일정 안내가맹점 즉시
L2 본사 연계무상 재제작·부품·환불본사 승인
L3 본사 직접분쟁·보상·법적본사 CS 전담
로그
모든 컴플레인은 손님 프로필에 기록. 본사가 반복 유형 분석 후 제품·매뉴얼 개선.
손님 불편 2번에 대한 기준. 무관심도, 과한 밀착도 금지. 손님은 따라다니는 건 싫어하지만 완전히 방치하면 어색해함. 신호를 읽고 때맞춰 접근.
입장 0~30초 방치·추적 금지
행동
가볍게 한 번 인사. "편하게 둘러보세요." 이후 1.5m 거리 유지, 따라다니지 않기.
금지
첫 30초 영업 멘트 · 가격부터 꺼내기 · 뒤를 졸졸 따라다니기
신호 포착 접근 타이밍
신호
같은 안경 2회+ 만짐 · 거울 2회+ 봄 · 두 개 비교 · 두리번 · 눈 마주침
멘트
"그 모델 마음에 드세요? 그거 9사이즈로 나와서 얼굴에 맞춰 드릴 수 있어요. 써보실래요?"
근거
강요가 아닌 정보 제공. 베러비전의 강점(9사이즈·측정)을 자연스럽게 전달.
신규 vs 단골 강도 분기
신규
여유 있게 응대. 측정·가상피팅 권유로 부담 완화. "온라인에서 미리 골라보셔도 돼요."
단골
프로필 불러와 바로 데이터로 안내. "지난 사이즈 그대로 있어서 바로 보여드릴게요."
이탈위험
부담 없이 안부 묻고 무료 재검 제안. 영업 말투 금지.
접객 데스크(counter)에서 손님 조회 시 접객 강도 자동 표시. 단골, VIP, 이탈위험별 맞는 말투 표시.
