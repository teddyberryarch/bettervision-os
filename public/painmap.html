CORE STRATEGY

손님을 어떻게 알아보고, 안 귀찮게 데이터를 모을까요

손님은 회원가입을 싫어해요. 번거로움을 0에 가깝게 줄이려면 전화번호 하나가 만능 키예요. 도수 이력을 전화번호와 이름으로 조회하는 게 업계 표준이라, 여기서 출발해요.

① 전화번호 = 식별 키방문하거나 예약할 때 전화번호만 받아요. 기존 손님이면 도수, 방문횟수, 선호가 바로 떠요. 신규 손님은 번호 1개로 시작해요.
② 카카오싱크 1탭회원가입 폼 대신 QR을 찍고 채널 친구추가를 1탭으로 끝내요. 가입 번거로움 없이 식별과 마케팅 동의까지 한 번에 돼요.
③ 알림톡 (정보성)전화번호와 비즈채널만 있으면 보낼 수 있어요. 예약 확인, 준비 완료, 1년 재검 알림을 보내요. 마케팅 동의가 없어도 손님을 다시 부를 수 있어요.
④ 친구톡 (광고성)채널 친구이면서 수신에 동의한 손님에게 보내요. 신상품, 프로모션, 손님 그룹별 발송을 해요. 마케팅의 중심은 카톡이에요.

참고로 레티나(안경업계 점유율 50%)가 이미 손님관리, 검안이력, 손님모니터, 본사 대시보드를 하고 있어요. BETTERVISION은 CRM을 새로 만드는 게 아니라 본사 데이터 귀속 + 9사이즈 측정표준 + 가상피팅 + 카톡 마케팅으로 차별화하고 하나로 묶어야 해요.

1
사이즈 맞는지 일일이 써봐야 함
해법: 카메라로 사이즈 측정. 있음 measure.html에 안면측정(카메라)과 9사이즈 환산이 있어요.
매장에 가기 전에 손님 앱에서 직접 재고 내 9사이즈 확정
2
조용한 매장 뻘쭘 · 접객 부담 · 몇 개 못 써보고 삼
해법: 가상 추천·피팅으로 부담 제거. 있음 recommend 가상피팅 + 있음 manual 접객강도 가이드(무관심도 과잉도 아니게).
접객 강도 가이드(말 걸 타이밍·거리감) 매뉴얼. 무관심하지도, 지나치지도 않게
손님이 폰으로 미리 골라오면 접객은 확인·업셀만
3
어떤 모델 있는지 모름 · 가서 봐야
해법: 전 모델 온라인 게시 + 사이즈 매치·벌림각 커버 판정. 있음 catalog (PB 9사이즈 제공 + 메이커 매치%·벌림각 판정).
모델별 내 사이즈 매치% + "벌림각 조정으로 커버 가능/불가" 판정 표시
4
렌즈 가격·정보 안 나옴 · 즉흥 결정
해법: 렌즈 가격·특성 기재. 있음 pricing 렌즈 굴절률×기능 가격표.
렌즈 카탈로그: 등급(굴절률·코팅·기능)별 가격·특성 투명 공개
5
눈에 잘 맞는지 확신 안 섬 · 안경사 신뢰
해법: 검안 시스템·안경사 신뢰도로 확신. 있음 exam + 있음 trust(면허·장비·프로세스 투명).
검안 과정·정밀도 손님 설명(시스템 투명화) + 안경사 면허·경력 프로필
6
콘택트 가격·색·특징 안 나옴
해법: 콘택트 가격·특징 모델별 기재. 있음 pricing 콘택트 카탈로그 + 있음 shop 구매(샌드박스 가정).
콘택트 카탈로그: 모델·색·도수범위·가격·특성. 온라인 판매는 샌드박스 통과 후
7
눈탱이(바가지) 걱정
해법: 눈탱이 안 치게 강조. 있음 pricing 표준가 보증 + 있음 quote 견적서 자동 발급.
본사 권장가 공개: 판매가는 매장이 정함, 결제 전 견적서
견적서 자동 발급: 프레임+렌즈+옵션 명세, 결제 전 투명
렌즈 등급별 가격표 공개 · 후기/평점 · "표준가 보증" 배지
8
메이커 안경 어디 있는지 모름
해법: 제휴 메이커 가격·사이즈 + 내 사이즈 매치. 있음 catalog 메이커 매치%·벌림각 판정(실데이터 입력 필요).
취급 메이커 온라인 게시(가격·사이즈) + 모델별 내 사이즈 매치 판정
9
재구매 매번 방문·검안 번거로움
해법: 손님 데이터 저장 + 검안 트래킹. 있음 profile 통합(도수 이력·시력추세·재구매).
통합 프로필에 도수·사이즈 저장, 재구매는 원클릭(검안 생략 가능 여부 안내)
검안 기록으로 시력 변화를 보고, 재검이 필요할 때만 안내
10
선글라스는 온라인으로 사고 싶음
해법: 선글라스 온라인 + 도수 재구매·콘택트(샌드박스). 있음 shop(선글라스=합법 / 도수재구매·콘택트=샌드박스 가정·표시).
선글라스 온라인 스토어(비도수=합법): 치수·추천·결제·배송
도수 안경 재구매는 규제 샌드박스 신청 후 픽업/온라인 배송 시도 (콘택트도 샌드박스 후)
